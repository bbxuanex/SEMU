# SEMU — ShuiMu Emulator

> 面向 RISC-V 的系统级指令集模拟器与轻量级操作系统实验平台

**Attention:**
- 由于shuimushi在攻克这门功课的时候还是一个*大一新兵蛋子*，整个coding过程*极其痛苦*并且大量的借助了gpt的帮助，因此目前该repo可以认为是*一个作业答案*，参考价值并不很大。
- 但是shuimushi借助ics功课本身建立了比较系统的对计算机系统的认识，可以认为是shuimushi的*启蒙老师*了。
- shuimushi在不久的将来还会回来*手撕*这位启蒙老师的。

SEMU 基于南京大学 Project-N 实验框架完成，以 RV32IM 为主要实现与验证目标。项目通过解释执行方式模拟处理器指令与体系结构状态，并在此基础上构建交互式调试、执行追踪、硬件抽象、异常处理、文件系统和系统调用支持，打通用户程序从指令执行到底层设备访问的完整链路。

该项目的重点不是单独实现某个算法，而是在代码中理解并连接计算机系统的不同层次：一条指令如何改变处理器状态，访存请求如何到达模拟设备，用户程序如何通过异常陷入操作系统，以及操作系统如何借助 Abstract Machine 使用底层机器。

## 系统架构

~~~mermaid
flowchart TB
    A[Navy 用户程序] --> B[Nanos-lite<br/>ELF 加载、文件系统、系统调用]
    B --> C[Abstract Machine<br/>TRM / IOE / CTE]
    C --> D[NEMU<br/>RV32IM 指令解释与设备模拟]
    D --> E[Linux 宿主机]
~~~

| 模块 | 作用 |
| --- | --- |
| `nemu/` | 系统级指令集模拟器，负责指令执行、处理器状态、内存访问、设备模拟与调试追踪 |
| `abstract-machine/` | 与具体机器解耦的硬件抽象层，为上层软件提供统一的运行时、I/O 与异常接口 |
| `nanos-lite/` | 轻量级操作系统，提供 ELF 装载、Ramdisk 文件系统、设备文件及基础系统调用 |
| `navy-apps/` | 用户态应用与运行库，用于验证从应用到模拟硬件的完整执行链路 |

## 核心实现

### RV32IM 指令解释执行

- 基于模式匹配表完成指令译码与解释执行，覆盖约 56 条指令匹配规则。
- 支持算术逻辑、移位比较、Load/Store、条件分支和函数跳转。
- 实现 RV32M 乘除法与余数指令，并处理除零和有符号溢出等边界情况。
- 实现 CSR 访问、`ecall`、`mret` 及基本异常状态维护。
- 维护通用寄存器、程序计数器和处理器控制状态，确保零号寄存器语义正确。

### 交互式调试器 SDB

- 支持连续运行、单步执行、寄存器查看和内存扫描。
- 实现表达式词法分析与递归求值，支持十进制、十六进制、寄存器引用、内存解引用以及算术、比较和逻辑运算。
- 使用固定容量监视点池管理调试状态，在表达式值变化时暂停执行并输出新旧值。
- 提供批量表达式测试命令，用于验证表达式求值器的正确性。

### 执行追踪与验证

- ITrace：记录指令执行及反汇编信息。
- 环形指令缓冲区：保留异常发生前的最近执行现场。
- MTrace：记录物理内存与设备映射区域的读写行为。
- FTrace：解析 ELF 符号表，将跳转地址映射为函数名并按调用深度输出调用/返回关系。
- STrace：记录系统调用编号、参数与返回值。
- 保留与 Spike/QEMU 等参考模型进行差分测试的接口，用于逐指令状态校验。

### 轻量级操作系统链路

- 解析 ELF Header 和 Program Header，将 `PT_LOAD` 段装载到目标地址并初始化 BSS。
- 基于 Ramdisk 实现定长文件系统及 `open/read/write/lseek/close` 等文件操作。
- 将串口、键盘事件、帧缓冲区和显示信息统一抽象为特殊文件。
- 实现 `yield`、`brk`、`gettimeofday` 等基础系统调用。
- 打通 `ecall → 异常处理 → 系统调用分发 → 返回用户程序` 的运行路径。
- 通过 Abstract Machine 对定时器、键盘、GPU 和音频设备提供统一访问接口。

## 构建

建议在 Linux 环境下进行构建。首先设置各子项目路径：

~~~bash
export SEMU_HOME=$(pwd)
export NEMU_HOME=$SEMU_HOME/nemu
export AM_HOME=$SEMU_HOME/abstract-machine
export NAVY_HOME=$SEMU_HOME/navy-apps
~~~

配置并编译 NEMU：

~~~bash
cd "$NEMU_HOME"
make menuconfig
make -j"$(nproc)"
~~~

具体运行目标取决于所选择的 ISA、测试程序和文件系统镜像。各模块的构建方式可参考其目录中的 README 和 Makefile。

## 项目边界

- 当前主要实现与验证目标为 **RV32IM**。
- 仓库保留 Project-N 的多 ISA 模块化组织方式，但不同 ISA 后端的完成程度并不相同。
- 差分测试、设备和操作系统功能是否启用取决于构建配置。
- 本项目定位为基于教学框架完成的系统实现与扩展，不将上游框架代码表述为个人从零开发。
